# MiniMart OS

Nepal-focused mini-mart management and POS platform.

## Documentation-First Development

This repository uses a controlled AI-assisted engineering workflow.

Start with:

1. `AGENTS.md`
2. `brain/BRAIN.md`
3. `brain/CURRENT_STATE.md`
4. `docs/OPENCODE_START_PROMPT.md`

Do not ask an agent to build the entire application in one task.

Execute one task at a time from `/plans/`.

Every task requires testing and an audit.

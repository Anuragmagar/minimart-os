# PHASE 05 — PRODUCTS

## Execution Rules

Execute one task at a time. Do not continue automatically.
Read `/AGENTS.md` and relevant `/brain/*.md` before each task.
Blocking ambiguity requires stopping and asking the user.
Every completed task requires tests, self-audit, CURRENT_STATE update, and AUDIT_LOG entry.

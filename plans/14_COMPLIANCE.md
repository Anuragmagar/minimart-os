# PHASE 14 — COMPLIANCE

## Execution Rules

Execute one task at a time. Do not continue automatically.
Read `/AGENTS.md` and relevant `/brain/*.md` before each task.
Blocking ambiguity requires stopping and asking the user.
Every completed task requires tests, self-audit, CURRENT_STATE update, and AUDIT_LOG entry.

## TASK 14.01 — Identify Requirements

### Objective
Identify applicable Nepal requirements using authoritative sources.

### Dependencies
Use completed tasks recorded in `brain/CURRENT_STATE.md`.

### Allowed Scope
Only files/modules required to satisfy this task.

### Forbidden Scope
No unrelated refactors, speculative features, architecture changes, or later tasks.

### Requirements
- Implement the objective according to the project brain and architecture.
- Preserve applicable business rules.
- Follow security and testing requirements.

# Definition of Done

A feature is not complete merely because the application compiles.

## Required

- domain behavior implemented
- persistence implemented where needed
- API implemented where needed
- local database implemented where needed
- offline behavior considered
- sync behavior considered
- authorization implemented
- audit behavior implemented
- user-facing errors handled
- tests implemented
- tests passing
- documentation updated
- current state updated
- audit log updated

## Financial/Inventory Features

Additionally require:
- atomicity
- idempotency
- concurrency consideration
- historical immutability
- invariant/reconciliation tests

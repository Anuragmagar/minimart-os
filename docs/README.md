## Workflow
1. Put this pack into the repository.
2. Run the Foundation Readiness Review.
3. Resolve blocking decisions.
4. Execute one task at a time.
5. Independently audit each task.
6. Update CURRENT_STATE and AUDIT_LOG.
7. Move to the next task only after the previous task passes.
